# admin/

這個目錄只放一個檔案：`vault.enc`。

它是**加密後的 GitHub token**，公開檔案，會跟著網站一起發布。
還沒建立的話，`#/admin` 會告訴你去跑：

```bash
node scripts/make-vault.mjs
```

## 為什麼公開放一個加密檔是可以的

因為它裡面沒有可以被「繞過」的東西。密碼不是拿來跟什麼比對的 ——
它是 AES-GCM 的解密金鑰來源。密碼錯，解出來就是垃圾，GitHub 回 401。

但這不代表它沒有風險。完整的說明與 token 外洩時的處理步驟，
見專案根目錄 README 的「後台安全模型」。

## 不要放進這個目錄的東西

- 明文 token
- 密碼、密碼的雜湊、密碼提示
- 任何備份檔（`vault.enc.bak` 之類的舊版本會讓攻擊者有兩份密文可以比對）
